# Stargazing

[Play!](https://thezachirons.itch.io/star-hating)

Winner of 2025 PGM Autumn Game Jam - Best Music

The Moon is tired of stargazing, he's ready to do some star-HATING!

Controls:

WASD or Arrow Keys to move.
Double tap W/S or ↑/↓ to dash.
Space/Left Click to shoot.

Throw rocks at stars! Reach heaven through violence!
